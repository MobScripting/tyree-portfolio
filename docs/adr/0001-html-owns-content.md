# HTML owns every fact; the 3D Stage is decoration

Recruiters skim, ATS parsers and search crawlers can't read WebGL, and some visitors have reduced motion turned on or no GPU. So all content lives in semantic HTML, and the Stage is aria-hidden and purely decorative. We picked a hybrid scroll story over a fully explorable 3D world (Bruno Simon style) to keep the site skimmable and fast. Never put information only in the 3D scene.
