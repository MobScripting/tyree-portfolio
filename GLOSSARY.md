# Tyree Chappell Portfolio

A 3D-enhanced portfolio site meant to get Tyree hired for full-stack/SaaS and AI/LLM engineering roles. It does this by presenting software he has built and run.

## Audience

**Track**:
One of the two job targets the site serves: **Full-stack** (SaaS/product engineering, with DevOps/platform kept open) or **AI** (LLM application engineering, plus IT-ops automation).
_Avoid_: Mode, persona, audience variant

**Recruiter**:
Anyone screening Tyree for a role: recruiter, hiring manager, or interviewer. It's the visitor every page is designed for.
_Avoid_: User, client, customer

## Content

**Case study**:
An in-depth, verifiable account of one featured project: problem, architecture, key decisions, stack. It has its own page.
_Avoid_: Project page, write-up, portfolio item

**Featured project**:
A project that gets a case study and a section in the scroll story. Currently FlowPulse, AD Account Manager, and the agentic-workflow study.
_Avoid_: Main project, hero project

**Lab item**:
A smaller project shown only as a card, with no case study (e.g. TendedEarth, Lawn Titans).
_Avoid_: Side project, experiment, misc

**Proof stat**:
A number or fact about a project that can be checked against its source (e.g. data model count, endpoint count, live deployment). It is never a projected or invented metric.
_Avoid_: Metric, KPI, achievement

**Role tag**:
A label on a resume bullet or project naming which Track(s) it supports. It decides what each resume variant includes.
_Avoid_: Category, filter tag

**Resume variant**:
One of the two downloadable resumes (Full-stack, AI), both generated from the same content.
_Avoid_: CV version, alt resume

## Presentation

**Scroll story**:
The single home page whose sections play out in order as the visitor scrolls, with the 3D scene reacting to them.
_Avoid_: Landing page, home, one-pager

**Stage**:
The WebGL scene fixed behind the page's HTML. It is decorative and never the only place information appears.
_Avoid_: Canvas, 3D view, background

**Device**:
A procedurally modeled laptop or phone on the Stage whose screen shows a footage loop.
_Avoid_: Mockup, model, prop

**Scene keyframe**:
The camera and Device pose tied to one scroll-story section.
_Avoid_: Shot, waypoint, state

**Footage loop**:
A short, muted, sanitized screen recording (with a poster still) of a featured project, played on a Device screen.
_Avoid_: Video, demo, clip

**Assistant**:
"Ask Tyree": the on-site chat that answers questions about Tyree's work, grounded only in case studies and resume content, with citations.
_Avoid_: Chatbot, bot, AI agent
